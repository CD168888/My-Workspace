# 目录规范（My-Workspace）

本文件是仓库目录结构与命名规则的**唯一权威约定**。任何新增文件、目录、自动化脚本都应遵循此处规定，确保结构统一、易检索。

## 一、分层原则

按「文件的角色 / 用途」归类，而非按时间或来源平铺。核心分层：

| 层 | 含义 | 是否可改写 |
|----|------|-----------|
| 数据源 sources | 每日原始采集，单一事实来源 | 只沉淀，不回改 |
| 汇总 reports | 由数据源派生的周期提炼 | 可随数据源重建 |
| 创意 creative | 扩展趣味产物，独立于主线 | 可失败，不影响主线 |
| 脚本 scripts | 确定性逻辑（解析 / 打分） | 代码，需评审 |
| 界面 web | 展示层（GitHub Pages 看板） | 独立部署 |
| 文档 docs | 说明与规范 | 文档 |
| 模板 templates | 写作模板 | 统一字段口径 |

## 二、顶层结构

```
My-Workspace/
├── .gitignore                  版本库忽略规则（系统/IDE/语言/私密）
├── README.md                   仓库总览（指向 docs/ 与 每日新闻/）
├── index.html                  重定向到 每日新闻/web/（仅作 Pages 兼容）
├── docs/                       全仓说明与规范
│   ├── README_创意.md          创意模块说明
│   └── 目录规范.md             本文件
└── 每日新闻/                   项目根（自动化与网页的基准路径）
    ├── sources/   归档/        年-月/YYYY-MM-DD.md
    ├── reports/   汇总/
    │   ├── weekly/  周报/       周报_YYYY-Www.md
    │   └── monthly/ 月报/       月报_YYYY-MM.md
    ├── creative/  创意/
    │   ├── 人格主播/ 金句/ 打假/ 副业榜/ 情绪/ 漫画/ 盲盒/ 徽章/
    ├── scripts/   脚本/        common.py、score.py
    ├── web/                   index.html + assets/（看板）
    └── templates/ 模板/        每日新闻模板.md
```

> 说明：中文语义目录名（`归档`、`汇总`、`创意`、`脚本`、`模板`）予以保留，因为它们已被 4 个自动化任务的 prompt 硬编码引用。如需改为英文别名，必须同步更新自动化 prompt 与前端的取数路径。

## 三、命名规则

1. **日期文件**
   - 日：`YYYY-MM-DD`（如 `2026-08-07.md`）
   - 周：`YYYY-Www`，`ww` 为 ISO 周序号、零填充两位（如 `2026-W32.md`）
   - 月：`YYYY-MM`（如 `2026-08.md`）
   - 全程使用零填充，保持位数一致。

2. **文件名格式**：`类型_周期.md`
   - 例：`周报_2026-W32.md`、`月报_2026-08.md`、`打假_2026-08-07.md`、`金句_2026-08.md`
   - 漫画图片：`月报_YYYY-MM.png`（每月一张，置于 `创意/漫画/images/`）。

3. **空目录占位**：统一使用 `.gitkeep`（不要使用 `.gitkeep.md`）。

4. **目录名**：以中文语义为主；英文别名仅作为说明写进本文档，不强制出现在路径中。

## 四、归属逻辑（文件该放哪）

| 文件类型 | 目录 | 理由 |
|----------|------|------|
| 每日原始新闻 | sources/归档 | 事实来源，不回改 |
| 周 / 月提炼 | reports/汇总 | 由 sources 派生，可重建 |
| 人格主播 / 金句 / 打假 / 副业榜 / 情绪 / 漫画 / 盲盒 / 徽章 | creative/ | 扩展产物，隔离主线 |
| 解析 / 打分脚本 | scripts/ | 确定性逻辑，自动化调用 |
| 看板页面 | web/ | 展示层，独立部署 |
| 写作模板 | templates/ | 统一字段口径 |
| 说明文档 / 规范 | docs/ | 唯一权威说明 |

## 五、Git 与 Pages 注意事项

- `.idea/`、`.workbuddy/`、`__pycache__/` 等已在 `.gitignore` 忽略，不进版本库。
- GitHub Pages 当前从仓库根（`main` / root）发布；根 `index.html` 仅为重定向到 `每日新闻/web/`。若改为从 `每日新闻/web` 目录发布，可删除根 `index.html`。
- 移动 / 重命名任何被自动化引用的目录（归档、汇总、创意、脚本、模板）后，**必须同步更新 4 个自动化任务的 prompt 与前端 `web/assets/app.js` 的取数路径**，否则采集 / 展示链路会断裂。
