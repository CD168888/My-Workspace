# 创意扩展模块说明（趣味 / 新颖性）

本目录在「每日 AI 新闻」主链路之外，叠加五条可玩性扩展线，全部按**分类目录**统一存放，便于回溯与网页展示。

## 目录结构

```
每日新闻/
├── 创意/                      ← 所有创意产物统一根目录
│   ├── 人格主播/YYYY-MM-DD.md  每日不同人设口吻的重述版（周一分析师 / 周三毒舌 / 周五段子手）
│   ├── 金句/YYYY-MM.md         每日一条扎心/幽默吐槽，按月追加
│   ├── 副业榜/YYYY-MM.md       每周副业机会四维度评分排行榜（门槛/成本/变现速度/竞争度）
│   ├── 打假/YYYY-MM-DD.md      每日「谣言粉碎机」：挑 1 条夸张新闻交叉核查 + 靠谱度评级
│   ├── 情绪/YYYY-MM.md         每周 AI 情绪温度计（情绪均值 / 热度均值）
│   ├── 漫画/images/月报_YYYY-MM.png   每月四格漫画（ImageGen 生成，中文漫画/国漫风格）
│   ├── 漫画/YYYY-MM.md         漫画文案脚本（4 格分镜 + 一句话梗概）
│   ├── 盲盒/YYYY-MM-DD.md      冷知识盲盒：非固定时段的 AI 冷知识
│   └── 徽章/成就.md            连续观察天数里程碑（如满 100 天生成纪念）
└── 脚本/                     ← 确定性打分脚本（自动化用 Bash 调用）
    ├── common.py              解析每日 md（与前端 app.js parseDaily 同口径）
    └── score.py               情绪/热度打分、副业四维度评分、连续天数判定 → 输出 JSON
```

## 各扩展线说明

| 方向 | 触发 | 存放 | 复用 |
|------|------|------|------|
| 人格化娱乐（人格主播 / 金句） | 每日 08:30 | 人格主播/、金句/ | 每日采集 + 邮件 |
| 反向打假（谣言粉碎机） | 每日 08:30 | 打假/ | WebSearch 交叉核查 |
| 游戏化（副业榜 / 情绪 / 徽章） | 每周五 / 每日 | 副业榜/、情绪/、徽章/ | score.py 打分 |
| 多模态（每月四格漫画） | 每月末 | 漫画/ | ImageGen 生成图片 |
| 惊喜盲盒（冷知识） | 每日 12:30 | 盲盒/ | 随机冷知识 |

## 运行方式

自动化任务在写档后调用：

```bash
python 每日新闻/脚本/score.py --date YYYY-MM-DD
```

脚本输出 JSON（情绪/热度/副业评分/连续天数），由自动化据此生成对应的创意 md 文件并提交。
确定性逻辑（打分、排序、连续天数）放在脚本里保证可复现；创意性文本（人设口吻、吐槽、漫画分镜）由自动化模型生成。
