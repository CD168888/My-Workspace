# 每日新闻 · AI 动态统一管理仓库

本文件夹用于**自动收集、整理与归档每日 AI 领域重要动态**，是新闻数据的统一存放位置。
所有内容按「年-月」归档，并定期生成「周报 / 月报」汇总，方便后续查阅与回顾。

---

## 一、目录结构

```
每日新闻/
├── 归档/                          # 【核心】按“年-月”归档
│   └── 2026-08/                   # 月份目录（YYYY-MM）
│       └── 2026-08-07.md          # 当日新闻文件（YYYY-MM-DD.md）
├── 汇总/                          # 周期性汇总
│   ├── 周报/                      # 每周五 18:00 后生成
│   │   └── 周报_2026-W32.md
│   └── 月报/                      # 每月最后一天 18:00 后生成
│       └── 月报_2026-08.md
├── 模板/
│   └── 每日新闻模板.md             # 每日新闻文件标准模板
└── README.md                      # 本说明文档
```

---

## 二、自动化任务

本仓库由 WorkBuddy 自动化任务驱动，共三个定时任务：

| 任务 | 执行时间 | 输出文件 | 邮件推送 |
|------|----------|----------|----------|
| 每日 AI 新闻采集 | 每天 08:30 | `归档/YYYY-MM/YYYY-MM-DD.md` | 整理后的纯文本 |
| 每周 AI 新闻汇总 | 每周五 18:00 | `汇总/周报/周报_YYYY-Www.md` | 整理后的纯文本 |
| 每月 AI 新闻汇总 | 每月最后一天 18:00 | `汇总/月报/月报_YYYY-MM.md` | 整理后的纯文本 |

> **说明**：邮箱推送使用 `agent-mail` 连接器。由于该连接器的安全策略，每次外发都需你一键确认；文件归档部分完全自动。

---

## 三、每日文件格式

每日归档文件 `归档/YYYY-MM/YYYY-MM-DD.md` 包含：

- 重点关注方向：AI coding、具身智能、行业蓝海/新机会
- 3–5 条高价值动态，每条包含：
  - **事件内容简述**
  - **值得关注的原因**
- 可选的「蓝海市场 / 副业机会」小节（有则列出，无则省略）

具体格式参见 `模板/每日新闻模板.md`。

---

## 四、汇总文件格式

- **周报**：汇总本周（周一至周五）每日文件，提炼 3–7 条核心趋势。
- **月报**：汇总当月所有周报，提炼 5–10 条核心趋势。
- 汇总文件同样保存 Markdown 格式作为档案，邮件发送时转换为纯文本。

---

## 五、手动补充

如需手动补充某条新闻，直接在对应日期的 md 文件末尾追加即可。结构保持统一，便于后续汇总。
