## 1. 编码智能体竞争重心转移：从「更强模型」到「工程化 + 可治理 + 自我进化」

本周编码智能体连续发版，卖点没有一个是"更聪明的模型"，而是"花更少 token 保持连贯""把并行隔离做成一等原语""递归删除前先拦一道"。10-12 GitHub 将本地沙箱（local sandboxing）设为可用、微软透露 HydraFusion 编排器在本地与云端动态路由、本地调用 MAI-Code-1.1-Flash 不计推理费；10-13 腾讯开源内部自用的 TeamAI（MIT 许可，用 Git 做技能评审与版本管理、已适配 16 种 Agent），阿里 Qoder Fast 模式号称提速 150%、Token 降 27%；10-14 哈佛工作论文（718 家企业、约 3 亿工作事件）戳破"编码智能体=生产力"——代码 +30%、提交 +20%、PR +23%，但评审耗时 +49%、已解决 issue 数无统计显著提升，同周 Anthropic 发布 Claude Haiku 5.5（单任务成本低约 75%）、微软推出 MXC SDK 1.0 稳定版沙箱与 Microsoft-Decision-1；10-15 Artificial Analysis 榜单洗牌，Sonnet 5.5 / GPT-6.1 Sol / Gemini 4 Argon 登顶，单任务成本从约 $14.19 到 $1.04 差十三倍，Cloudflare 开源决策模型 Clef（只输出概率、调用免费）；10-16 Claude Code v2.1.296 可单调用读超大文件、子 Agent 自动压缩上下文，Codex 0.162 落地托管式 git worktree 隔离并行，Cursor CLI 加递归/通配/强制删除护栏，"自我改进"路线集中爆发——SelfSearch 用 4.03 美元无奖励搜索追平 Codex、Meta RankEvolve 准确率 45.8%→62.5%、Hugging Face 把主流 harness 改造成 RL 环境。

**为什么重要**：竞争焦点从"谁的模型更强"转向"怎么让 Agent 真正塞进团队工作流并可控、跑得更稳更安全"。哈佛研究给了"上 Agent 就提效"叙事一记证据级冷水——更多代码活动 ≠ 更多完成的工作，交付瓶颈在 review 与 test 而非 generate。对团队，工程化基础设施（worktree 隔离、prompt 缓存命中率、护栏审批）比换模型更值得投入；对个人副业，切入口也应从"代写代码"转向"审代码 / 补测试 / 做质量护栏"。

## 5. 前沿模型竞争加剧：Meta Muse Wonder 与「自我进化」路线集中爆发

本周模型层既有重量级新玩家入场，也有范式级新路线涌现。10-13 Meta 发布 Muse Wonder，官方称历经 14 个月攻坚抵达"前沿级能力"梯队，在代码编写、金融 / 法律等专业场景对标 ChatGPT 与 Claude，并加入跨会话 Active Memory 与面向长任务的 Active Focus，随后为个人助手 Muse 订阅提供底层算力；10-16 "自我改进"路线集中爆发——SelfSearch 用 4.03 美元无奖励搜索搜出追平 Codex 的 harness、让 DeepSeek V4 Flash 在 Terminal-Bench 2.1 拿到 82.0%，Meta RankEvolve 把执行准确率从 45.8% 提到 62.5%，Hugging Face 将主流编码 harness 改造成 RL 环境。

**为什么重要**：Muse Wonder 让前沿模型牌桌添一位重量级玩家，多一个可选项往往意味着更良性的价格与接口竞争；而"自我进化"路线把竞争焦点从"谁的模型更强"推到"谁能让 Agent 自己变强、跑得更稳更安全"，模型的护城河正从静态权重转向持续学习与工程化闭环。对开发者，这是一个选择增多、但选型更需看真实任务复测而非官方宣传的阶段。
