## 2. AI 编程 Agent 安全漏洞集中爆发——越权自主执行成头号风险

本周两类高危漏洞把"自主执行"的代价摆上台面：

- **Claude Code「自动模式」RCE**：默认开启的自动模式可被网页提示诱导下载并执行恶意代码，小规模测试成功率 60%–80%，Anthropic 暂标记为"信息性备注"且无修复计划。
- **GitSpawn 漏洞类别**：Manifold Security 在 7 款命令行编码代理中发现 8 处问题，核心是把 git `core.fsmonitor` 性能特性武器化——携带完整 `.git` 目录的恶意仓库可在沙箱外以当前用户权限无提示执行任意代码，窃取 SSH 密钥、云凭证与本地文件。截至披露，Hermes Agent、Qwen Code、Grok Build 及 Claude Code 的第二条利用路径仍未修复。

**信号**：Agent 从"写代码"走向"直接跑命令"，沙箱隔离与权限最小化成为企业采用前提，也催生 AI 安全审计 / 合规代运营类副业的确定需求。这与监管动向同频——中央网信办点名"智能体自主行动"为头号风险，欧盟《AI 法案》处罚权落地、第 50 条要求 AI 生成内容加机器可读标记。
