- **条数**：4 条（与归档一致）
- **打分指标**：连续观察 109 天；情绪均值 0.5；热度均值 2.5；副业总分 11

各位早。今天先讲一条需要拆口径的消息，再讲三条把成本摊开的账。我的判断放在每条后面，不和事实混在一起。

第一条，黎曼猜想的 AI 证明。11 月 20 日 Anthropic 的数学家阿尔珀格声明与 Claude 合作完成证明，公开出来的是一份 4 页说明加约 1700 万行 Lean 代码，25 万页的自然语言草稿没公开。萨瑟兰独立编译跑通了，张凯羿用 128 核服务器跑了约 8 小时 22 分也通过了。到这里为止，能确认的是代码内部逻辑自洽。巴泽德提醒的下一步还没做：确认代码里的定理陈述就是广义黎曼猜想本身。邓煜说可读版本出现前不评论，克雷数学研究所要求期刊发表加两年验证。我的判断是，把这件事写成"AI 攻克数学神山"太早，写成"AI 在形式化验证里过了两轮独立编译"更准确。热度 2，情绪 0。

第二条，NBER 的 35275 号工作论文。50 多万名 GitHub 开发者，自动补全、同步智能体、异步智能体分别把提交量累计抬高 30%、180%、240%，但发布版本只增加 30%，项目数增加 80%。同步智能体用户的新增代码是 7 倍、删除是 12.2 倍，新建分支多 79%，新仓库首月后停更的比例从 2021 年的 60% 升到 2026 年的 69%。作者给的解释是替代弹性只有 0.23，评审、测试、发布没跟着扩。这是未经同行评审的工作论文，数据关键部分来自微软内部，作者自己也披露了潜在相关关系。我的判断是方向可信、倍数别当定论：它至少把衡量口径从"写了多少"推到"发出了多少"。热度 3，情绪 1。

第三条，OpenAI 的账。研究员人均每天调用的 Agent 按 API 标价折算约 2400 美元，用量前 10% 的人单日能到 2.3 万美元，内部 Agent 开销已经是研究员薪酬的两倍。同一周他们的数据库维护事故持续 211 分钟，ChatGPT 和 API 请求失败率峰值 75%，原因是两个承担实时查询的只读副本同时失效，而认证也压在这条链路上。我的判断是，这两件事得连起来看：Agent 用得越深，成本和故障面都从模型本身挪到了鉴权、容灾和验证。热度 3，情绪 0。

第四条，具身智能的账本。纽氏达特招股书显示，来自具身机器人的收入从 2023 年的 30.70 万元到 2025 年的 9662.82 万元，增长 1235.46%，但平均单价从 2024 年的 1256 元降到今年上半年的 598 元，毛利率从 55.49% 降到 48.05%。另一边，越疆的机器人在深圳影院每天工作 14 小时、日销超千杯；伯克利用单卡 3 小时的训练结果超过 128 卡 7 天。我的判断是收入曲线向上和单价曲线向下并不矛盾，前者说明有订单，后者说明零部件正在标准化；真正该盯的是稳定在岗时长和单台成本。热度 2，情绪 1。

收尾。今天四条里，三条的共同词是验证：数学证明等比对运行，代码产出等发布，机器人等交付。副业那条也一样，OPC 社区省下的是房租和算力接入费，不是把交付风险免了。109 天观察下来，我的结论没变——生成变便宜以后，值钱的是能核验、能追责、能持续交付的那一层。
