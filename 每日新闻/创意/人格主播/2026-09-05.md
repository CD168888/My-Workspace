**1. GitSpawn 漏洞曝光：7 款 AI 编码代理被"仓库配置"武器化**
9月1日，安全公司 Manifold Security 披露了一类叫 GitSpawn 的漏洞，在 7 款命令行 AI 编码代理里一共找到 8 处问题。原理不复杂但很危险：git 有个 `core.fsmonitor` 性能开关，代理为了快，会在后台静默跑 `git status`/`git diff` 收集上下文，而恶意仓库能把自己的指令塞进 `.git/config`，让程序以你的身份、在沙箱外、没有任何提示地执行任意代码，顺手把 SSH 密钥和云凭证打包带走。目前已经修好的有 Claude Code（2.1.196）、Codex、Cursor、Goose；截至 9月1日重测，Hermes Agent、Qwen Code、Grok Build 以及 Claude Code 的第二条路径还没修。普通 clone 不受影响，风险只在"以文件形式拿到带 .git 的仓库"时触发。建议所有在不可信目录跑编码代理的团队立即升级，并用 `git config --global core.fsmonitor false` 兜底。

**2. 车企竞逐"第二增长曲线"：海内外近 20 家主流车企集体下场造人形机器人**
这两天多家媒体把镜头对准了车企跨界"造人"。不完全统计，海内外已有近 20 家主流车企布局人形机器人，国际侧有特斯拉、现代、宝马、奔驰、三菱、雷诺，国内侧则是小鹏、比亚迪、奇瑞、广汽、长安、理想、蔚来、赛力斯、吉利、北汽、一汽、上汽、东风等一众老对手再次会师。小鹏 IRON 首轮超 9 亿美元融资、投后估值超 63 亿美元；广汽孵化的慧仑科技完成超亿元融资，GoMate Mini 已部署近 50 台并拿到近千万元订单；奇瑞墨甲墨茵 M1 定价 28.58 万元，成了国内首款车企自研直售的人形机器人；比亚迪自研"尧舜禹"计划 2026 年内部部署 2 万台；蔚来则选择"投而不造"。背后逻辑很清楚：汽车主业利润率已经跌到 2.9%，而车端与机器人约 70% 技术、超 50% 供应链可复用，自有工厂就是训练场。行业普遍认为 2026–2028 是从样机到万台量产的关键窗口。

**3. Coding Agent 进入"自主合并 PR"时代：工具链一周内密集升级**
9月的前三天，AI 编程工具链几乎集体更新。VS Code 1.136 推出了 Agent Merge 预览——代理会自己消化评审意见、修掉失败的检查、解决冲突并重跑工作流，直到 PR 可以直接合并；GitHub Copilot 的代码审查也从"评论者"升级成可以"批准"PR（默认关闭，管理员开启）；Cursor 0.45 支持多仓库上下文，云代理还能订阅 PR、Slack 线程或定时任务自动唤醒；Claude Code 2.1.259 则新增了组织级 MCP 统一下发和无人值守的无头模式，并原生支持 GitLab MR。开发者从"写代码"进一步退到"审代码"，代理开始自己跑通合并闭环，CI/CD 与代码所有权的边界正在被改写。

**4. AI 副业蓝海：智能体"调试+落地"外包，叠加微短剧合规红利**
2026 被称为 AI 智能体落地元年，但绝大多数实体店、小微企业、工作室根本不会自己搭 Agent，于是"AI 智能体调试与落地外包"成了一片蓝海——帮客户搭客服 AI、运营 AI、库存管理 AI，单笔服务费几百到几千、复购率还高。与此同时，9月1日广电总局《微短剧发展管理办法》正式落地，原创合规的 AI 微短剧进入流量扶持加广告分成加带货变现的红利期，不用真人出镜就能批量产出高清原创。再加上围绕本地硬件的"AI 部署服务"，也是低门槛副业方向。不过要提醒一句：凡是主打"保证月入、卖课为主"的同类项目，大概率是坑，落地还是得以真实客户和可复盘数据为准。
