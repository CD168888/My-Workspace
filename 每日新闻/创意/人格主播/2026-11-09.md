# 人格主播 · 严肃分析师｜2026-11-09

> 人设：严肃分析师。今天不玩梗，只看数据怎么说话。

今天四件事，我按「生成之后发生了什么」这条线串一下。

**1. GitHub 的两条曲线方向相反。**
一边是单周 12 亿次提交、同比翻四倍多；另一边是 PR 评审时长在高采用团队里涨了 441%。把代码写快很容易，难的是有人看得完。GitHub 自己把「验」单列为四阶段之一，说明它也没真解决拥堵，只是把问题命名了。给管理者的提醒很直接：别拿提交量和采纳率当 KPI，那两个数会自动涨，跟交付价值没关系。

**2. 编码智能体的地盘在往外扩。**
Copilot 这周进了 Xcode 和 JetBrains Air，靠的是 ACP 这个越来越像 LSP 的「标准插座」；Claude Code 顺手加了「没人确认就直接拒」的无人值守开关，Codex 也上线了能同时盯多个 agent 的命令中心。智能体正在从「装在自家 IDE 里的助手」变成「嵌进任何编辑器、没人看管也能跑的后台设施」。对做中间层的人来说，这比追模型版本更稳。

**3. 进博会把具身智能的尺子换了一把。**
智元不再只报「卖了多少台」，而是抛出「有效智能工时」——10 月常态化口径下累计超 6.2 万个，覆盖五类场景，120 台 G2 进了广州地铁，单台在医院跑满 170 小时。同期还有约 2 万台的出海合作意向。从「造多少台」到「干了多少活」，这个转向比任何融资额都更能说明行业进入交付定价阶段。

**4. 重庆三个 90 后把「招投标」做成了能跑的一人公司。**
李璞先试 AI 短剧，发现改十几次是常态、边际收益低，转去做投标决策智能体「知彼」，覆盖找标到写标全流程，俩月仅智谱 GLM 就烧了 178 亿 token，现在国资背景企业想收购。这不是「训个大模型」的故事，是「把行业 know-how 包成智能体、按项目交付」的故事——副业能不能成，卡在比客户多走那两步，不在技术本身。

今天这四件事串起来是一个信号：AI 的瓶颈和机会，都从「生成」挪到了「之后」——之后谁来审、之后怎么接入、之后干成了没有、之后怎么交付。生成这道大题，基本做完了。
