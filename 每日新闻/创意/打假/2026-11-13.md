# 谣言粉碎机 · 2026-11-13

## 原声称
> "Mistral Large 4 是开源权重里最强的编程模型，Terminal-Bench 4.0 拿了 41%，比预览版涨了 13 个点。"

## 核查
- Mistral 官方公告明确：Large 4（Le Chonk）为 1 万亿总参数（约 500 亿激活）、100 万 token 上下文、原生多模态；Terminal-Bench 4.0 确为 **41%**，较预览版 **+13pt**，同时输出 token **少 30%**；AA Coding Agent Index **48%**，与 GLM-5.3 持平但每任务**少 47% token**；恶意请求拒绝率 **96.6%**（开源最高），B3 agent 安全基准攻击抵抗 **97.1%**。
- AIToolsRecap（11/8）逐条核对：41% / +13pt / 48% tied with GLM-5.3 using 47% fewer tokens，与官方一致；并指出 HF 仓库名标 A52B，与官方"49B 激活"有小幅出入。
- DEV Community 日报（11/9）独立确认：Terminal-Bench 4.0 41%（+13pt、−30% 输出）、AA Coding Agent Index 48% 与 GLM-5.3 持平、盲测编码偏好排在 Claude Opus 5.5 之后、开源最高。

**需要修正的地方**："最强"要加定语。在 token 效率与防御安全维度 Mistral 领先；综合编程榜它与 GLM-5.3 并列第一梯队，并非无争议地"全面最强"。另外"约 500 亿激活"在不同来源标注略有出入，以官方 49B 为准。

## 评级
★ ★ ★ ★（靠谱，但"最强"应限定在效率/安全维度，综合榜为并列）
