# 谣言粉碎机 · 2026-08-21

## 今日核查对象：Anthropic 年化营收突破 650 亿美元反超 OpenAI，IPO 估值剑指 2 万亿

### 原声称
多家媒体今日报道：Claude 制造商 Anthropic 年化营收运行率（run rate）已超 650 亿美元，约为去年底的 7 倍、年中披露的 2 倍以上，在增速上反超 OpenAI；市场对其年内潜在 IPO 的估值目标指向 2 万亿美元。OpenAI CFO 同周称"2027 年或更早将成为上市公司"。

### 核查
- **650 亿是"运行率"而非实际营收**：该数字出自"知情人士"口径，经 Axios、TradingKey 等转引，是按近期收入年化推算的投影值，不是已审计的已确认收入。OpenAI、Anthropic 等均未官宣精确财务数。
- **增速可信但基数跳跃大**：从去年底约 90 亿 run rate 到 650 亿（约 7 倍），在强企业 API 需求下激进但非不可能；此前披露年中 run rate 约 300+ 亿，"年中→年底 2 倍+"的曲线自洽。
- **"反超 OpenAI"需看口径**：OpenAI 含 ChatGPT 消费端体量更大，Anthropic 的"反超"更可能成立在企业 API / 增速侧，而非总营收。两者直接比"总营收"并不对等。
- **2 万亿是媒体/市场预期，非官宣**：没有任何公司文件确认该估值；它与 OpenAI CFO 同期"2027 或更早上市"的表态一样，属于双方上市前的预期管理。

### 评级
**靠谱度：★★★（趋势可信，措辞须打折）**
核心方向——Anthropic 企业需求爆发、估值与 IPO 预期上行——成立且有多个来源呼应。但"650 亿"是 run-rate 投影而非落袋营收，"2 万亿"是媒体目标而非公司承诺，"反超 OpenAI"仅在增速/企业侧严格成立。引用时建议改写为"年化运行率约 650 亿美元、IPO 估值预期高达 2 万亿"。
